# 🕷️ SpiderTrack

SpiderTrack is a gamified productivity web application inspired by Spider-Man’s fast-paced world, futuristic technology and progression systems.

Instead of completing boring tasks, users complete **missions**, gain **XP**, level up their skills and track their productivity through an interactive futuristic dashboard designed with a subtle Spider-Verse inspired aesthetic.

---

# ✨ Features

* 🎯 Mission tracking system
* 📈 Hero progression and leveling
* ⚡ Gamified productivity experience
* 🧩 Reusable React components
* 🎨 Modern futuristic UI with Tailwind CSS
* 🌌 Glassmorphism-inspired design
* 📱 Responsive layout foundation

---

# 🛠️ Tech Stack

## Frontend

* React

* Tailwind CSS

## Concepts Practiced

* React Components

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/MRTN74/spidertrack.git
```

## Navigate into the project

```bash
cd spidertrack
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```
